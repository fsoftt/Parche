Tu centro multimedia, con tus addons

Parche es un centro multimedia para Android (celular y Android TV), Windows y Roku. Muestra el catálogo y reproduce el contenido de los addons que tú agregas. Es compatible con el protocolo de addons de Stremio.

Addons

Cómo agregar addons

Parche no incluye ni aloja contenido y no trae addons de fuentes preconfigurados. Sin addons funciona como catálogo; para reproducir, agrega los que tú elijas.

  1. Abre Ajustes. Busca la sección de addons de fuentes.
  2. Pega la URL del addon. Sirve la dirección del manifest.json o la base del addon; también se acepta stremio://…. Solo se admiten direcciones http:// y https://.
  3. Repite para los subtítulos. Hay una lista aparte de addons de subtítulos (OpenSubtitles viene por defecto).
  4. Opcional: escribe tu clave de TMDB (themoviedb.org/settings/api) y ajusta idiomas, calidad máxima y descargas solo con WiFi.

En Roku

Escribir una URL con el control es incómodo. Abre el diálogo de teclado en pantalla y usa el teclado de la app móvil de Roku para pegar la URL desde el portapapeles del teléfono.

Para quitar un addon, enfoca su fila en Ajustes y pulsa * en el control.

Instalar

Descarga e instalación

Android y Android TV

Un mismo APK sirve para celular y para TV.

  1. Descarga el APK desde las releases o, si no hay una, desde el artefacto parche-android-apk de GitHub Actions.
  2. Ábrelo en el dispositivo. Android pedirá permitir la instalación de apps desconocidas (de fuentes desconocidas) para el navegador o gestor de archivos que uses.
  3. Confirma la instalación y abre Parche.

En Android TV puedes pasar el APK con una memoria USB o una app de archivos.

Windows

Por ahora se compila desde el código. Necesitas Windows 10 1809 o superior, el SDK de .NET 10 y el workload maui-windows.

dotnet workload install maui-windows
dotnet build src/Parche.App/Parche.App.csproj `
  -f net10.0-windows10.0.19041.0

El resultado es un .exe suelto (sin MSIX) en src\Parche.App\bin\Debug\net10.0-windows10.0.19041.0\win-x64\. Esa carpeta completa se puede copiar a otro equipo.

Roku

Instalar en Roku, paso a paso

La versión para Roku es un proyecto aparte, escrito en BrightScript: fsoftt/ParcheRoku. No está en la tienda de Roku; se instala en modo desarrollador ("sideload"). Necesitas un Roku (probado en un Roku Express) y una PC en la misma red.

1. Activar el modo desarrollador

  1. Ve a la pantalla de inicio del Roku (no dentro de un canal).
  2. Con el control pulsa, sin pausas largas: Inicio ×3, Arriba ×2, Derecha, Izquierda, Derecha, Izquierda, Derecha. Si no pasa nada, repítelo más rápido.
  3. Se abre Developer Settings. Anota la IP que aparece (por ejemplo 192.168.1.16).
  4. Elige Enable installer and restart y acepta el acuerdo del SDK (puede pedir bajar hasta el final del texto).
  5. Crea una contraseña de desarrollador. Es solo para instalar canales (usuario rokudev), no la de tu cuenta Roku. El Roku se reinicia.

Para comprobar que quedó activo, desde la PC: curl.exe http://IP_DEL_ROKU:8060/query/device-info debe incluir <developer-enabled>true</developer-enabled>.

2. Empaquetar el canal

Con Node.js instalado, dentro de la carpeta del repositorio ParcheRoku:

npm install
npm run package

Genera dist/ParcheRoku-<versión>-public.zip. Antes valida el código y corre las pruebas.

3. Instalar en el Roku

Desde el navegador

  1. Abre http://IP_DEL_ROKU en la PC. Usuario rokudev y tu contraseña del paso 1.
  2. En Development Application Installer pulsa Upload, elige el .zip y luego Install (o Replace si ya había una versión).

Con un solo comando

Empaqueta, instala y abre el canal (necesita Node 18 o superior).

# PowerShell
$env:ROKU_IP = "IP_DEL_ROKU"
$env:ROKU_PASS = "CONTRASEÑA"
npm run deploy

# bash / macOS / Linux
ROKU_IP=IP_DEL_ROKU ROKU_PASS=CONTRASEÑA npm run deploy

O con curl, sin Node

curl.exe --digest -u rokudev:CONTRASEÑA -F "mysubmit=Install" -F "archive=@dist/ParcheRoku-0.1.00001-public.zip" http://IP_DEL_ROKU/plugin_install

En Windows PowerShell 5.1 escribe curl.exe: curl a secas es un alias de otro comando. La respuesta debe incluir Install Success. El canal aparece en Inicio como Parche con la etiqueta dev.

4. Agregar addons

Abre el canal, entra a Ajustes y agrega tus addons. Para pegar la URL usa el teclado de la app móvil de Roku (ver Cómo agregar addons).

Notas

  • Solo puede haber un canal en modo desarrollador: si instalas otro, o desactivas el modo desarrollador, Parche se borra, y sus ajustes también.
  • Actualizar es volver a empaquetar e instalar: los ajustes guardados se conservan.
  • La IP del Roku puede cambiar si el router la reasigna. Vuelve a mirarla en Developer Settings o en Configuración → Red → Acerca de.
  • Para desinstalar, abre http://IP_DEL_ROKU y pulsa Delete.

Para desarrolladores

Plugins y puntos de extensión

Parche es un cliente neutral de addons. Quien quiera ofrecer algo adicional lo compila por separado y lo enlaza con un archivo de props; sin él, la app se compila y funciona igual, solo con los addons que agregue el usuario.

IStreamSourceProvider

En Core. Devuelve direcciones de addons de fuentes adicionales (GetAddonUrls(AppSettings)). El motor las une con las del usuario, sin repetidos.

IStreamResolver

En App. Convierte una opción que no trae enlace directo en una URL reproducible, con progreso y precarga. Sin ningún resolvedor, esas opciones se descartan.

IDownloadResolver

En App. Descarga completa de opciones sin enlace directo; la cola y la descarga HTTP común las hace la app.

IPluginSettingsSection

En App. Agrega una fila en Ajustes que abre una página propia del plugin, construida en C#.

Composición

  1. MauiProgram es static partial class y declara static partial void AddExternalSources(IServiceCollection).
  2. Parche.App.csproj importa $(ParchePluginsProps): por defecto ..\..\..\Parche.Plugins.props, o la ruta que indiques con -p:ParchePluginsProps=<ruta>. Con un valor que no exista (por ejemplo none) no se importa nada.
  3. Ese archivo agrega ProjectReference y un Compile que implementa el método parcial y registra tus piezas.

Los ajustes de un plugin se guardan como JSON por clave (GetPlugin<T> / SetPlugin<T>). Detalles en ARCHITECTURE.md.

// Parche.Plugins.props
<Project>
  <ItemGroup>
    <ProjectReference Include="..\MiPlugin\MiPlugin.csproj" />
    <Compile Include="..\MiPlugin\Registro.cs" />
  </ItemGroup>
</Project>

// Registro.cs
partial class MauiProgram
{
    static partial void AddExternalSources(IServiceCollection s)
    {
        s.AddSingleton<IStreamSourceProvider, MiProveedor>();
        s.AddSingleton<IPluginSettingsSection, MisAjustes>();
    }
}

Arquitectura

Cómo está hecho

Parche.Corenet8.0, sin interfaz: catálogo, cliente de addons, ranking de fuentes, subtítulos, ajustes y biblioteca.
Parche.App.NET MAUI (net10.0-android y net10.0-windows). MVVM, textos en español, inglés y portugués, y puntos de extensión para plugins.
ReproducciónExoPlayer (Media3) en Android y LibVLC en Windows. Roku es un canal aparte en BrightScript + SceneGraph.
Catálogo (TMDB o Cinemeta)    ─►  títulos, géneros, temporadas
Addons de fuentes (los tuyos) ─►  opciones de reproducción
Addons de subtítulos          ─►  pistas externas
                   │
        Parche.Core · ParcheEngine ──► Parche.App (MAUI)
                                        └─► ExoPlayer (Android) / LibVLC (Windows)

Compilar y probar

Requisitos: SDK de .NET 10 con el workload maui-android y Java 21.

dotnet test tests/Parche.Core.Tests
dotnet build src/Parche.App/Parche.App.csproj -f net10.0-android
dotnet build src/Parche.App/Parche.App.csproj -f net10.0-windows10.0.19041.0

GitHub Actions corre los tests en cada push y pull request a main, y genera el APK de Android al publicar en la rama release.
