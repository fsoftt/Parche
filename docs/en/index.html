Your media center, powered by your addons

Parche is a media center for Android (phone and Android TV), Windows and Roku. It shows the catalog and plays content from the addons you add. It is compatible with the Stremio addon protocol.

Features

Everything you need to watch

A streaming-service style interface designed for the phone, the TV with a remote, and the desktop.

Catalog from TMDB or Cinemeta

Browse, search and filter by category. Cinemeta needs no key; with a TMDB key you get data in your language and more rows.

Continue watching

Remembers where you stopped in each title and resumes from Home.

My list

Save what you want to watch later and find it again in its own tab.

Offline downloads

Download to watch without internet, with a queue and resume. You can limit downloads to WiFi.

Preferred audio language

Options are ordered by your languages, with Latin American Spanish first (then Spanish from Spain and English), and a maximum quality you choose.

Configurable subtitles

Add as many subtitle addons as you like: all are queried, tracks are merged and filtered by your languages.

Automatic next source

If a source fails, Parche tries the next one in the list without sending you back.

Made for the TV remote

Android TV with a side menu and D-pad navigation; Roku with visible focus across the whole channel.

Addons

How to add addons

Parche does not include or host any content and ships with no preconfigured source addons. Without addons it works as a catalog; to play something, add the ones you choose.

  1. Open Settings. Find the source addons section.
  2. Paste the addon URL. Either the manifest.json address or the addon base works; stremio://… is also accepted. Only http:// and https:// addresses are allowed.
  3. Repeat for subtitles. There is a separate list of subtitle addons (OpenSubtitles is the default).
  4. Optional: enter your TMDB key (themoviedb.org/settings/api) and adjust languages, maximum quality and WiFi-only downloads.

On Roku

Typing a URL with the remote is awkward. Open the on-screen keyboard dialog and use the keyboard of the Roku mobile app to paste the URL from your phone's clipboard.

To remove an addon, focus its row in Settings and press * on the remote.

Install

Download and install

Android and Android TV

The same APK works on phone and TV.

  1. Download the APK from the releases or, if there is none, from the parche-android-apk artifact in GitHub Actions.
  2. Open it on the device. Android will ask you to allow installing unknown apps (from unknown sources) for the browser or file manager you use.
  3. Confirm the installation and open Parche.

On Android TV you can move the APK over with a USB drive or a file app.

Windows

For now it is built from source. You need Windows 10 1809 or later, the .NET 10 SDK and the maui-windows workload.

dotnet workload install maui-windows
dotnet build src/Parche.App/Parche.App.csproj `
  -f net10.0-windows10.0.19041.0

The result is a loose .exe (no MSIX) in src\Parche.App\bin\Debug\net10.0-windows10.0.19041.0\win-x64\. That whole folder can be copied to another machine.

Roku

Installing on Roku, step by step

The Roku version is a separate project written in BrightScript: fsoftt/ParcheRoku. It is not in the Roku store; it is installed in developer mode ("sideloading"). You need a Roku (tested on a Roku Express) and a PC on the same network.

1. Enable developer mode

  1. Go to the Roku home screen (not inside a channel).
  2. On the remote press, without long pauses: Home ×3, Up ×2, Right, Left, Right, Left, Right. If nothing happens, try again faster.
  3. Developer Settings opens. Write down the IP shown (for example 192.168.1.16).
  4. Choose Enable installer and restart and accept the SDK agreement (you may need to scroll to the end of the text).
  5. Create a developer password. It is only for installing channels (user rokudev), not your Roku account password. The Roku restarts.

To check it is active, from the PC: curl.exe http://ROKU_IP:8060/query/device-info should include <developer-enabled>true</developer-enabled>.

2. Package the channel

With Node.js installed, inside the ParcheRoku repository folder:

npm install
npm run package

This produces dist/ParcheRoku-<version>-public.zip. It validates the code and runs the tests first.

3. Install on the Roku

From the browser

  1. Open http://ROKU_IP on the PC. User rokudev and your password from step 1.
  2. In Development Application Installer click Upload, pick the .zip, then Install (or Replace if a version was already there).

With a single command

Packages, installs and opens the channel (needs Node 18 or later).

# PowerShell
$env:ROKU_IP = "ROKU_IP"
$env:ROKU_PASS = "PASSWORD"
npm run deploy

# bash / macOS / Linux
ROKU_IP=ROKU_IP ROKU_PASS=PASSWORD npm run deploy

Or with curl, no Node needed

curl.exe --digest -u rokudev:PASSWORD -F "mysubmit=Install" -F "archive=@dist/ParcheRoku-0.1.00001-public.zip" http://ROKU_IP/plugin_install

In Windows PowerShell 5.1 type curl.exe: plain curl is an alias for another command. The response should include Install Success. The channel shows up on the home screen as Parche with a dev label.

4. Add addons

Open the channel, go to Settings and add your addons. To paste the URL use the Roku mobile app keyboard (see How to add addons).

Notes

  • Only one developer-mode channel can exist: if you install another one, or disable developer mode, Parche is deleted, along with its settings.
  • Updating means packaging and installing again: saved settings are kept.
  • The Roku IP may change if the router reassigns it. Check it again in Developer Settings or under Settings → Network → About.
  • To uninstall, open http://ROKU_IP and click Delete.

For developers

Plugins and extension points

Parche is a neutral addon client. Anyone who wants to offer something extra builds it separately and links it with a props file; without it, the app builds and works the same, using only the addons the user adds.

IStreamSourceProvider

In Core. Returns addresses of additional source addons (GetAddonUrls(AppSettings)). The engine merges them with the user's, without duplicates.

IStreamResolver

In App. Turns an option that has no direct link into a playable URL, with progress and preloading. With no resolver registered, those options are dropped.

IDownloadResolver

In App. Full download of options without a direct link; the queue and the common HTTP download are handled by the app.

IPluginSettingsSection

In App. Adds a row in Settings that opens the plugin's own page, built in C#.

Composition

  1. MauiProgram is a static partial class and declares static partial void AddExternalSources(IServiceCollection).
  2. Parche.App.csproj imports $(ParchePluginsProps): by default ..\..\..\Parche.Plugins.props, or the path you pass with -p:ParchePluginsProps=<path>. With a value that does not exist (for example none) nothing is imported.
  3. That file adds ProjectReference items and a Compile item that implements the partial method and registers your pieces.

A plugin's settings are stored as JSON per key (GetPlugin<T> / SetPlugin<T>). Details in ARCHITECTURE.md (in Spanish).

// Parche.Plugins.props
<Project>
  <ItemGroup>
    <ProjectReference Include="..\MyPlugin\MyPlugin.csproj" />
    <Compile Include="..\MyPlugin\Registration.cs" />
  </ItemGroup>
</Project>

// Registration.cs
partial class MauiProgram
{
    static partial void AddExternalSources(IServiceCollection s)
    {
        s.AddSingleton<IStreamSourceProvider, MyProvider>();
        s.AddSingleton<IPluginSettingsSection, MySettings>();
    }
}

Architecture

How it is built

Parche.Corenet8.0, no UI: catalog, addon client, source ranking, subtitles, settings and library.
Parche.App.NET MAUI (net10.0-android and net10.0-windows). MVVM, UI text in Spanish, English and Portuguese, and plugin extension points.
PlaybackExoPlayer (Media3) on Android and LibVLC on Windows. Roku is a separate BrightScript + SceneGraph channel.
Catalog (TMDB or Cinemeta)    ─►  titles, genres, seasons
Source addons (yours)        ─►  playback options
Subtitle addons              ─►  external tracks
                   │
        Parche.Core · ParcheEngine ──► Parche.App (MAUI)
                                        └─► ExoPlayer (Android) / LibVLC (Windows)

Build and test

Requirements: .NET 10 SDK with the maui-android workload, and Java 21.

dotnet test tests/Parche.Core.Tests
dotnet build src/Parche.App/Parche.App.csproj -f net10.0-android
dotnet build src/Parche.App/Parche.App.csproj -f net10.0-windows10.0.19041.0

GitHub Actions runs the tests on every push and pull request to main, and builds the Android APK when publishing to the release branch.
